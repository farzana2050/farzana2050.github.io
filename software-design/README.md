# Software Design and Engineering Enhancement

## Artifact Overview

The artifact selected for the Software Design and Engineering category is an Event Tracking Android application developed during my previous computer science coursework. The application was designed to allow users to create and manage events through an Android interface while using application logic and database functionality to maintain event information.

I selected this artifact for my CS 499 ePortfolio because it demonstrates several important areas of software engineering, including object-oriented programming, application architecture, user-interface development, data management, validation, testing, and maintainability. It also provided a strong opportunity to demonstrate my ability to evaluate existing software and improve it rather than simply create a new application from the beginning.

## Enhancement

For the CS 499 enhancement, I reviewed the original implementation and identified areas where the application could be improved using stronger software engineering practices. I worked with the application's Java classes, database functionality, Android user-interface components, and supporting resources while preserving the original purpose of the application.

The enhancement focused on improving code organization, readability, maintainability, validation, and error handling. These improvements made the application's responsibilities clearer and helped create code that would be easier for another developer to understand, test, maintain, and expand.

I also considered the interaction between different parts of the application. Changes to application logic can affect database operations and the user interface, so the enhancement required me to consider the application as a complete software system rather than as a collection of independent files.

## Skills Demonstrated

This artifact demonstrates my ability to apply software design and engineering principles to an existing application. The enhancement required skills in object-oriented programming, Android development, code organization, input validation, error handling, debugging, and application maintenance.

The project also demonstrates my ability to analyze existing source code and determine where improvements provide value. Instead of replacing the original application, I preserved its intended functionality while improving the quality and maintainability of its implementation.

Working with the Java classes, XML resources, application interface, and database-related functionality also strengthened my understanding of how multiple software components work together within a larger application.

## Course Outcome Alignment

This enhancement demonstrates progress toward the Computer Science program outcome involving the use of well-founded techniques, skills, and tools to implement computing solutions that provide value and accomplish specific goals. The enhanced Android application applies software engineering practices to improve an existing functional solution.

The artifact also supports the outcome involving the design and evaluation of computing solutions. I evaluated the original implementation, identified areas that could be improved, implemented changes, and considered the effects of those changes across multiple application components.

In addition, the enhancement supports the security-focused program outcome through attention to input validation, error handling, and safer software design practices. These considerations helped me recognize that application quality includes not only functionality but also reliability and the prevention of avoidable software weaknesses.

The documentation and organization of the enhanced artifact also support professional technical communication by making the purpose and structure of the software easier for other developers and stakeholders to understand.

## Reflection

Enhancing an existing Android application taught me that software engineering involves more than adding new functionality. Improving existing software requires understanding how the current implementation works, identifying weaknesses, determining which changes provide meaningful value, and testing those changes without damaging existing functionality.

One of the challenges was working with dependencies between the application's user interface, program logic, and database functionality. A change in one area could affect another part of the application, which required careful testing and debugging. This reinforced the importance of modular design and understanding the responsibilities of different software components.

The enhancement also strengthened my ability to read and evaluate existing code. I learned to look beyond whether a program simply works and consider readability, maintainability, validation, error handling, and long-term software quality. These are skills that I will continue to apply as I pursue professional work in software and full-stack development.
