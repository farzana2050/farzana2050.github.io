## Enhancement Narrative

The artifact selected for this enhancement is an Event Tracking Android application. I selected this artifact because it demonstrates important software design and engineering concepts, including application structure, user interaction, data management, validation, and maintainability.

For the CS 499 enhancement, I improved the original application to demonstrate stronger software engineering practices. The enhancement focused on improving the organization and quality of the existing code while preserving the purpose of the application. I worked with the application's Java classes, database functionality, user-interface components, and supporting Android resources.

The enhanced artifact demonstrates my ability to analyze existing software and identify opportunities for improvement rather than simply developing an application from the beginning. The work required me to consider code readability, modularity, validation, error handling, maintainability, and how different components of an application interact.

This enhancement also strengthened my testing and debugging skills. Modifying an existing application required careful attention to dependencies between the user interface, application logic, and database functionality. I learned that even relatively small design changes can affect multiple parts of an application and therefore need to be tested carefully.

Overall, this artifact demonstrates progress toward the CS 499 outcomes involving professional software development, computing practices and tools, communication of technical decisions, and secure software design. It also demonstrates my ability to evaluate an existing computing solution and improve its overall quality.
