# Algorithms and Data Structures Enhancement

## Artifact Overview

The artifact selected for the Algorithms and Data Structures category is the Treasure Hunt Game, an artificial intelligence project that uses reinforcement learning to train a pirate agent to navigate a maze and locate a treasure. I selected this artifact because it demonstrates algorithmic problem solving, decision-making logic, data structures, machine learning, and the evaluation of computing solutions.

The original artifact was developed as part of my previous computer science coursework. It provided a foundation for applying reinforcement-learning concepts through a deep Q-learning approach. For my CS 499 enhancement, I focused on improving the training process, testing the behavior of the intelligent agent, and evaluating whether the algorithm could consistently accomplish its intended goal.

## Enhancement

The enhanced version improves the deep Q-learning process used by the pirate agent to navigate the maze. The project uses Python, TensorFlow/Keras, experience replay, an epsilon-greedy exploration strategy, neural-network training, and repeated model evaluation.

During the enhancement, I reviewed and improved the training logic used to determine how the agent selects actions and learns from previous experiences. Experience replay allows previous state transitions to be stored and reused during training, while the epsilon-greedy strategy provides a balance between exploring new actions and selecting actions the agent has already learned to be effective.

I also tested and debugged the training process to verify that the algorithm operated correctly in the development environment. The final training and evaluation demonstrated that the agent could successfully navigate the maze and reach the treasure. The final evaluation achieved a 100% win rate, providing measurable evidence that the enhanced algorithm accomplished its intended objective.
