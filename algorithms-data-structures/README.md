# Algorithms and Data Structures Enhancement

## Artifact Overview

This artifact represents my work in the Algorithms and Data Structures category of the CS 499 Computer Science Capstone. I selected the Treasure Hunt Game because it demonstrates algorithmic problem solving, reinforcement learning, decision-making logic, and the use of data structures to support an intelligent agent.

## Enhancement

The enhanced version improves the deep Q-learning process used by the pirate agent to navigate the maze and reach the treasure. The project uses Python, TensorFlow/Keras, experience replay, an epsilon-greedy exploration strategy, target-network updates, and repeated model evaluation.

During the enhancement, I improved and tested the training logic so the agent could learn an effective navigation strategy. The final training run reached a 100% win rate and successfully completed the maze evaluation.
